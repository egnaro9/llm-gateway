Running llm-gateway via Pyodide. The wheel is built from main by CI.

How this works without a server: a browser tab can't listen on a port, so rather than fake an HTTP layer, the page hands each request directly to the same ASGI application uvicorn would serve, via FastAPI's TestClient. Same app object, same middleware stack, same code paths — only the socket is missing. The provider is the built-in deterministic mock, which is why there's no API key and no spend.
